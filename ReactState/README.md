# 🛒 Grocery Master - React State & Logic Mastery

A professional, high-performance shopping list application built to master **React State Management**, **Hooks**, and **LocalStorage Persistence**. This project is part of my "React Core Mastery" series.

## 🚀 Live Demo  https://mastering-react-core.onrender.com

## ✨ Key Features
- **Full CRUD Operations:** Add, Edit, Update, and Delete grocery items seamlessly.
- **Persistent Storage:** Uses `localStorage` so your list remains safe even after a page refresh.
- **Smart Search:** Real-time filtering to find items quickly in a long list.
- **Data Validation:** Prevents duplicate entries and empty/numeric-only inputs.
- **Dynamic UI:** Smooth state-based styling (Conditional rendering for Edit mode and Completed items).
- **Responsive Design:** Modern UI with Glassmorphism effects and gradient backgrounds.

## 🛠️ Tech Stack
- **Frontend:** React.js (Functional Components)
- **State Management:** `useState`, `useEffect` (Hooks)
- **Language:** JavaScript / TypeScript
- **Styling:** Dynamic Inline CSS (Object-based)

## 🧠 Logic Mastery Highlights
In this project, I focused on:
1. **Initial State Logic:** Using a callback function in `useState` to avoid unnecessary parsing of `localStorage`.
2. **Immutable Updates:** Handling complex array updates and nested object state without mutating the original state.
3. **Effect Cleanup:** Managing timers and side effects using `useEffect` cleanup functions.
